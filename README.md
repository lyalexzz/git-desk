# Git 桌面端

Windows 桌面客户端，用来查看和操作 Git 仓库。技术栈是 Electron + React。

目前对接：

- 自建 GitLab
- 极狐 GitLab 私有部署
- 极狐 GitLab SaaS（[jihulab.com](https://jihulab.com)）
- [GitLab.com](https://gitlab.com)（登录页可选）

后续计划对接云效、码云（Gitee）、GitHub，这两类平台现在还不能登录。

## 环境

- Node.js 20
- Windows（`npm run dist` 打的是 Windows 安装包）
- 要在本机拉取代码，还需安装 [Git for Windows](https://git-scm.com/download/win)（自带 `ssh`）

## 从源码运行

在仓库根目录：

```powershell
npm install
npm run dev
```

`npm run dev` 会启动开发模式窗口。

打包 Windows 安装程序：

```powershell
npm run dist
```

安装包在 `dist/` 目录，文件名类似 `gitlab-desk-0.1.0-setup.exe`。安装时可自选目录，并创建桌面和开始菜单快捷方式「Git 桌面端」。

## 登录

登录页先选平台并填写服务器地址（SaaS 地址已预填）。三种方式：

| 方式 | 说明 |
| --- | --- |
| 个人访问令牌 | 在 GitLab「偏好设置 → 访问令牌」新建，勾选 **api**。jihulab.com、GitLab.com 和私有部署都可以用。 |
| 账号密码 | 仅私有部署。需要先配置 OAuth 应用（见下）。密码只用来换登录令牌，不保存在本机。新版 GitLab 往往已关闭客户端密码登录；开了双因素、LDAP、手机号或单点登录时，改用网页登录。 |
| 网页登录 | 打开 GitLab 官方登录页（支持双因素）。私有部署和 SaaS 都可以。jihulab.com、GitLab.com 不能在客户端里直接填密码，请用这种方式或个人访问令牌。 |

账号密码和网页登录都要先准备 OAuth 应用：

- 私有部署：管理员在「管理中心 → 应用」建一次，全公司共用。
- SaaS：在「偏好设置 → 应用」里自己建。
- 回调地址填登录页给出的地址（可复制）。
- 权限范围勾选 **api**。取消勾选「机密」后可以不填密钥。

内网自签证书：登录页或「设置」里打开「忽略 HTTPS 证书校验」。

登录令牌、OAuth 密钥和 AI 的 API Key 用系统加密后存在本机（Electron `safeStorage`），退出登录会清掉登录令牌。

## 功能

侧栏从左到右对应这些页面。顶部可用 **Ctrl+K**（macOS 为 ⌘K）打开全局搜索，可搜项目、打开中的合并请求 / Issue、待办，并快速跳转常用页面。

### 工作台

近 30 天的个人活动、最活跃项目、按项目看成员提交量。顶部数字可点进：待我审核的合并请求、我发起的进行中合并请求、指派给我的 Issue、待办数量。

### 待办与桌面通知

待办列表，可单条完成或全部标为已完成。设置里可开关桌面通知，并调整检查间隔（默认约 2 分钟）。新待办（待审核、流水线失败、被 @ 等）会弹出系统通知，点击通知回到待办页。

### 项目

项目列表支持按组筛选，也支持按组名搜索。点进项目后：

- **代码**：目录和文件浏览。Markdown 可预览或看源码，其他代码有语法高亮。
- **提交记录**：按分支或路径查看，可从某次提交进入回滚。
- **分支**：按最近更新或名称排序；新建分支；删除非默认、非受保护分支；批量删除；清理已合并分支。
- **标签**：搜索并查看，点标签可切到对应代码。
- **设置**：见下文「项目设置」。

项目页可以复制 SSH / HTTPS 地址。本机 Git 可用时，还可以一键拉取代码（见下节）。

### 本地仓库

侧栏「本地仓库」可**扫描本地文件夹**：选择本机目录后，会向下查找 Git 仓库，并按 `origin` 地址与当前登录服务器上你有权限的项目自动匹配（SSH / HTTPS 等价）；匹配成功会写入克隆记录。未匹配的也会列出，可打开文件夹查看。

已关联的仓库选中后可：

- 查看工作区状态（已暂存 / 未暂存 / 未跟踪）
- 暂存、取消暂存、填写说明后提交、推送到远端
- 切换本地分支（工作区有未提交修改时会提示先处理）
- 点文件查看本地 diff；也可拉取更新、用编辑器打开、忘记本地路径记录
- **提交记录**：按当前分支分页查看历史，点开可看说明与 patch

克隆弹窗里「在本地仓库打开」会跳到对应项目。

### 合并请求

按项目、状态筛选；可**新建合并请求**（源/目标分支、标题、描述、草稿、指派人）。打开一条后可以：批准或撤销批准、合并（可选压缩提交、删除源分支）、**编辑**标题/描述/草稿/指派人、看变更 diff。变更页支持**行内评论**（悬停行旁「＋」），讨论 Tab 可回复线程、解决 / 重新打开讨论。合并前会显示冲突、流水线、审批等检查结果。

### Issue

按项目查看，可新建 Issue，打开后看内容和评论。

### 流水线

按项目、状态、分支查看 CI/CD 流水线，可手动运行。打开一条流水线能看作业、读作业日志，并对作业或整条流水线取消、重试。

### 用户与权限

- 用户列表（管理员）：新建用户、封禁 / 解封、激活、批准注册。可重置密码（生成随机密码，可复制）。LDAP 账号的密码不在 GitLab 里改，界面上会禁用重置。
- 项目成员：添加、改角色、移除。从群组继承的成员要到 GitLab 群组里管理，这里只处理项目的直接成员。

自己的密码在「设置 → 当前账号 → 修改密码」。管理员可以直接设置；普通用户会打开 GitLab 的修改密码页。

### 项目设置

需要项目维护者或所有者。

- **受保护分支 / 受保护标签**：查看、添加、取消保护，设置谁可以合并、推送或创建。
- **常规**：名称、描述、可见性（私有 / 内部 / 公开）、默认分支。改名称不会改仓库路径。
- **合并请求**：合并方式、是否删除源分支、是否要求流水线通过等。审批人数属于付费功能，社区版上改了可能不生效。
- **CI/CD 变量**：增删改变量（环境范围、保护、掩码等）。

### AI 审核

在「设置 → AI」里填写 OpenAI 兼容接口：地址、API Key、模型。可选用预置服务商（DeepSeek、通义千问、智谱、Kimi、豆包、硅基流动、OpenAI、本机 Ollama），也可以填自定义地址。支持拉取模型列表、测试连接、自定义审核提示词。部分服务商拉不到模型列表时，直接输入模型名即可。

在合并请求里对当前 diff 做流式审核，可把结果发布成评论。审核正文会标明模型名称，并注明仅供参考。

### 分支回滚

在分支页或提交记录里打开。三种写法都走 GitLab API，不依赖本机工作区：

- **安全回滚（推荐）**：新建一个提交，让文件内容回到目标提交，历史保留。
- **强制回滚**：删掉分支再按目标提交重建，历史被改写。默认分支和受保护分支不能强制回滚。
- **撤销单个提交**：在分支上再做一个相反的提交。

操作前会检查分支是否又有新提交，避免盖住别人的改动。

### SSH 一键配置与拉取代码

在「设置 → SSH 与 Git」：

- 检测本机 Git 和 ssh。未安装时可从国内镜像或官网下载，装完点「重新检测」。
- **一键配置 SSH**：为当前服务器生成专用密钥（不覆盖已有密钥）、把公钥加到当前 GitLab 账号、写入 `~/.ssh/config`、再测试连接。也可以把已有公钥单独上传。
- **Git 提交身份**：写入全局 `user.name` / `user.email`。
- **默认克隆位置**：拉取代码时的默认父目录。

在项目里拉取：

- 协议可选 HTTPS 或 SSH（SSH 已测通时会默认 SSH）。
- 显示进度，可取消（取消会删掉未完成的目录）。
- HTTPS 使用当前登录令牌，令牌不写入仓库的 Git 配置；日志里的令牌会打码。
- 完成后可打开文件夹、用 VS Code 或 Cursor 打开、在终端打开。
- 已克隆的项目可以再「拉取更新」，只做快进（`--ff-only`）。本地有未提交修改、或和远端已经分叉时，需要自己在终端里处理，软件不会强制覆盖。
- 更完整的本机操作（暂存、提交、推送、切分支、看本地 diff）在「本地仓库」页。

## 已知限制

- **社区版受保护分支**：GitLab 社区版不能直接改「允许推送 / 允许合并」的角色，软件会先取消保护再按新设置重新保护（间隔很短）。如果这条规则里单独指定了用户、群组或部署密钥，重新保护后这些会丢失，需要到网页上补回去。若重新保护失败，分支会暂时处于未保护状态，请立刻重新添加。
- **AI 审核**看的是合并请求的 diff，不是仓库里的完整文件。单次有字符上限，超出的文件会跳过；GitLab 也只返回前 100 个变更文件。结果可能不完整，合并前仍需人工看。
- **回滚会改远程分支**。请先在测试分支上试。强制回滚会改写历史，已推送过的分支会影响其他人。含子模块或符号链接的变更无法做安全回滚。

## 数据放在哪

配置在本机 Electron 用户数据目录的 `config.json`（令牌等字段是密文）。软件不把 GitLab 密码写入这个文件。
